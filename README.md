# Minecraft Crossy Cat

A Crossy Road-style game featuring a Siamese cat with Minecraft-like blocky graphics. Navigate your cat across busy roads while avoiding traffic!

## Features

- **3D Minecraft-Style Graphics**: Built with Three.js for blocky, voxel-style visuals
- **Siamese Cat Character**: Detailed blocky cat with cream and brown coloring and blue eyes
- **Progressive Difficulty**: The game gets harder the further you progress
- **Dynamic Road Generation**: Infinite procedurally generated roads and safe zones
- **Collision Detection**: Realistic collision system with vehicles
- **Score System**: Earn points based on distance traveled
- **High Score Tracking**: Automatically saves your best score

## How to Play

1. Open `index.html` in a modern web browser
2. Click "Start Game" to begin
3. Use keyboard controls to move the cat:
   - **↑ / W**: Move Forward
   - **↓ / S**: Move Backward
   - **← / A**: Move Left
   - **→ / D**: Move Right

## Game Mechanics

- **Objective**: Guide the Siamese cat as far forward as possible while avoiding vehicles
- **Scoring**: You earn 10 points for each grid space moved forward
- **Difficulty**: Vehicle speed and spawn rate increase as you progress
- **Game Over**: Collision with any vehicle ends the game

## Technical Details

- Built with Three.js for 3D rendering
- Responsive design that adapts to window size
- Smooth animations and movement
- Shadow mapping for enhanced visual depth
- LocalStorage for persistent high score tracking

## Requirements

- Modern web browser with WebGL support
- Internet connection (for Three.js CDN)
